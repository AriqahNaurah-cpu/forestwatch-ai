# ForestWatch AI — Satellite & Deforestation Insights

Website pembelajaran interaktif tentang peran hutan tropis, deforestation alerts, citra satelit, dan penggunaan AI untuk mendukung pemantauan perubahan hutan.

## Fitur
- Penjelasan peran hutan tropis.
- Alur umum deforestation alerts dari citra hingga verifikasi.
- Pipeline ilustratif citra satelit → prapemrosesan → AI → tinjauan.
- Demo simulator prioritas tinjauan dengan data sintetis.
- Studi kasus patroli dan dashboard pemantauan.
- Desain responsif, menu mobile, dan tombol tema.

## Menjalankan
Buka `index.html` di browser. Tidak perlu server atau instalasi package.

## Deploy ke GitHub Pages
1. Buat repository publik, misalnya `forestwatch-ai`.
2. Upload `index.html`, `style.css`, `script.js`, dan `README.md` ke root repository.
3. Masuk **Settings → Pages**.
4. Pilih **Deploy from a branch**, branch `main`, folder `/(root)`, lalu klik **Save**.
5. Tunggu sampai GitHub menampilkan URL website yang aktif.

## Catatan
Materi ini disusun dari judul dan cuplikan yang terlihat pada screenshot webinar, bukan transkrip atau ringkasan terverifikasi dari seluruh video. Semua nilai pada simulator bersifat sintetis dan menggunakan aturan sederhana, bukan model AI yang dilatih atau sistem peringatan deforestasi operasional. Alert bukan bukti final deforestasi; verifikasi dan konteks lapangan tetap diperlukan.
